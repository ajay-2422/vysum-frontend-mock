# Vysum Static Frontend Mock

Static frontend demonstration for the project **Agentic AI for Video-Based Verification of Topical Eyedrop Adherence**.

No Node.js, React, database, AWS connection, or API key is required.

## Included mock results
- Contact Detected
- No Contact
- Indeterminate
- YOLO/video evidence
- Sensor evidence
- Mock VLM interpretation
- Deterministic signal fusion
- FSM temporal validation
- Audit information

All displayed values are sample data only. The JavaScript objects can later be replaced with responses from the real backend/API/cloud pipeline.
